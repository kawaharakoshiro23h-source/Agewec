## Asset Library

### 全公式写真のローカル保存

状態: `pending`

`asset_catalog.json`に登録され、利用・保存条件を確認できた公式写真を、
現在と同じファイル名形式で`assets_dl/`へダウンロードする。

目的:

- 自律実行中のダウンロード待ちをなくす
- URL切れや一時的な通信障害で生成が停止することを防ぐ
- ComfyUIへ入力画像をすぐ渡せるようにする
- オフライン実行を可能にする
- 同じ素材の重複ダウンロードを防ぐ

保存方針:

```text
asset_catalog.json
assets_dl/
  写真ファイル1.jpg
  写真ファイル2.jpg
  ...
```

実装時に記録する情報:

- `asset_id`
- タイトル
- 元画像URL
- 詳細ページURL
- ジャンル
- エリア
- ローカルパス
- 取得日時
- ファイルサイズ
- SHA-256
- 権利確認状態
- 権利確認日

注意:

- ローカル保存済みであることと、利用許諾済みであることを分けて管理する
- 利用・保存条件が不明な素材は自動取得対象にしない
- LLMへ毎回全画像を送らず、メタデータで候補を絞る
- 不足素材のみを選択後に自動取得するフォールバックも後から追加する

### 素材フィルタの再設計

状態: `pending`

現在は`target_award: 夜景賞`の場合、夜景ジャンルへ候補を絞っている。
「昼の活動から夕方を経て、最後に荘厳な夜景で締める」構成に対応するため、
賞の種類と各カットの素材条件を分離する。

検討項目:

- `time_of_day`: `day / dusk / night`
- `visual_role`: `opening / activity / transition / climax`
- `location`
- `subject`
- 最終夜景カットの必須条件
- 各属性からLLMへ渡す候補件数

実装順:

1. 全フェーズの現状仕様を確認する
2. Storyboardの素材要件Schemaを確定する
3. Asset Curatorの候補抽出ルールを変更する
4. 公式素材をローカルへ保存する
5. 不足素材の自動ダウンロードを追加する
6. 1カットのEnd-to-End実行で検証する
