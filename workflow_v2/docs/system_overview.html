AGEWEC 2026 — AIエージェント自律制作システム 概要

生成AI・AIエージェントが「企画 → 台本 → 素材選定 → 演出 → 動画生成 → 品質検査 → 編集 → 審査 → 証跡」までを自律実行する、北九州観光プロモーション動画の制作パイプライン。各工程はLLM/決定論処理で構成され、すべての工程の後段に「レビューゲート（自動 or 人間承認）」を持つ。

人間確認 重要マイルストーン（H1/H2/H3）で人が承認・修正指示 Review Gate 全ノード後段。always / on_exception / never を切替 出力形式 次工程へ渡す構造化データ（JSON）

全工程を貫く仕組み

Review Gate（各ノード後段）… always（毎回人が承認）／on_exception（失敗・低信頼・上限到達時のみ）／never（自動通過）をノード単位で選択。プリセット manual / supervised / autonomous で一括切替も可能。
人間確認（H1/H2/H3）… コンセプト・絵コンテ/素材/演出・最終提出、の3マイルストーンで人が承認・プロンプト修正・差し戻し。
Execution Guard… フェーズ別リトライ上限・総実行数・実行時間の上限を持ち、無限ループを防止。上限到達時は安全停止して人へエスカレーション。
バックエンド差し替え… 生成部（Image/Video Production）は共通インターフェースで、ローカルComfyUI(LTX)↔クラウドAPI を設定変更のみで切替可能。
Provenance… 各工程の判断理由・使用モデル・生成設定・修正履歴を構造化して保存＝再現性を担保。
